API reference

Rate limits

Every key is bucketed per endpoint. Requests over the ceiling get a 429 and a Retry-After header.

The v1 limits retire on 1 March

Keys still on v1 fall back to 60 requests a minute after that date. Move to v2 headers before then.

Common questions

Does a 429 count against my quota?

No. Rejected requests are not billed and do not consume budget.

Are limits per key or per workspace?

Per key. A workspace with four keys has four independent buckets.
