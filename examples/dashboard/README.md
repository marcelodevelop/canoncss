# Dashboard example

Analytics shell: topbar + `sidebar` layout, stat cards in a 4-col grid
(responsive to 2 then 1), activity feed and team list in a `split`.

Patterns shown: `sidebar` slots, `grid` `data-cols="4"`, badges as status
(`success`/`warning`/`error`/`info`), `select` control, avatars, dividers as
list separators, `data-truncate`.

Open `index.html` in a browser (build `dist/canon.css` first: `npm run build`).
