# Blog example

Long-form article at `data-width="prose"` (65ch measure), heading hierarchy
straight from the type scale, a card used as a pull-quote, tag badges, and a
"more writing" card grid.

Patterns shown: `centered` prose width, unstyled h1–h3 (the reset sizes
them), `divider`, badges as tags, `link`-variant buttons.

Open `index.html` in a browser (build `dist/canon.css` first: `npm run build`).
