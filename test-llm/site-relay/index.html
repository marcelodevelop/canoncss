How it works

From spec to shared mock in minutes

1. Import your spec

Drop in an OpenAPI or GraphQL schema — or paste a sample response. Relay generates realistic mock endpoints for every route, instantly.

2. Shape the behavior

Add latency profiles, auth rules, stateful sequences, and error scenarios. Test the 429s and 503s your happy-path staging server never throws.

3. Share the URL

Every mock gets a stable hosted URL. Point your app, your tests, or your CI at it — teammates see changes the moment you publish.

Features

Built for teams that ship in parallel

Versioned mocks

Every mock is versioned like code. Pin CI to a version, iterate on the next one, roll back in one click.

Stateful scenarios

Model real flows: create a resource, fetch it, delete it. Relay keeps per-session state so mocks behave like a real backend.

Chaos on demand

Inject timeouts, malformed payloads, and rate limits with a toggle. Find your retry bugs before your users do.

Request inspection

Every request to a mock is logged with headers, body, and timing. Debug integration issues without a proxy in sight.
